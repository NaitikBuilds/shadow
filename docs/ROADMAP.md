# SHADOW Roadmap

## Complete Phases

### V1.0 Core ✅
Consent, memory, semantic + temporal retrieval, privacy dashboard, wipe,
streaming LLM, Lite/Balanced/Active modes, graceful shutdown.

### V1.0 Perception ✅
Active window, OCR, typing dynamics, documents, calendar, clipboard,
knowledge graph (project/topic/file/person), adaptive observation budget.

### V1.0 Infrastructure ✅
Migrations, model manager, error taxonomy, CI, retention, crash recovery,
WAL mode, ARCHITECTURE + DECISIONS docs.

### V1.0 Proactive (Level 4) ✅
Insight framework, recovery, forecasting, decay, focus shield, style mirror,
clipboard actions, session memory, ambient tasks, focus patterns, recurring
patterns, intent notes, DND, feedback, redaction, PromptBuilder, taint,
quick capture, search panel, diagnostics panel.

### V1.0 Structured Screen (Phase 3.5) ✅
UIA element tree reader, window classifier, UIA text extraction, interactive
element extraction, URL/path detection, tab awareness, change detection,
adaptive cadence, observer integration, multi-monitor awareness, reading
position memory, stuck detector, UIA vs OCR comparison harness.

## Next Phases

### V1.0 Vision (Phase 3.6)
VLM backend, Moondream2 CPU, screen vision source, image file ingestion,
screen context queries, region capture / Circle-to-Ask.

### V1.0 Advanced Proactive (Phase 4)
Shadow Cloning, Ethical Mirror, Cross-Project Weaver, Silent Pair Partner,
meeting audio ASR, Meeting Prep, Post-Meeting Summary, Daily Digest,
Weekly Review, Notification Summarization.

### V1.0 Agent Foundation (Phase 4.5a/b)
Action Registry, first 4 low-risk actions, Permission Engine, Risk Classifier,
Rate limiter, audit log, undo, kill switch, confirmation UI, Agent Mode UX,
injection suite.

### V1.0 Agentic (Phase 5)
16 actions across risk tiers, `open_app`, UI automation actions, system
control, global dictation, MCP client, Drag-to-SHADOW.

### V1.0 Autonomous (Phase 6)
Missions with planner/executor, check-ins, limits, audit reports.

### V2.0 Snapdragon NPU (Phase 7, Deferred)
QNN EP, planner on NPU, battery-aware scaling.

### Packaging (Phase 8, Deferred)
MSIX, WinRT calendar, auto-update, onboarding wizard, export/import UI,
accessibility, localization.

## Post-v1.0
Encrypted multi-device continuity, domain packs, webcam posture, live
meeting ASR, browser companion extension.
