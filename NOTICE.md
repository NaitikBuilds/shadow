# NOTICE

## Project Status

SHADOW is a **personal work-in-progress project** currently under active development.

It is being built openly for learning, experimentation, and portfolio purposes. The repository is public so others can:

- Learn from the architecture and design decisions
- Follow the development process
- Provide feedback and suggestions
- See how a fully-local AI agent can be built

It is **not** ready for production use. APIs, file formats, and database schemas may change without notice.
